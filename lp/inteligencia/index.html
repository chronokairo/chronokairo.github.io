Chronokairo Coder (CKC)

Rust Native // Zero Dependencies

Agente Autônomo em Rust

Diferente de ferramentas pesadas em Node.js ou Electron, o CKC é compilado em binário nativo de Rust com zero dependências externas. Executa inspeção de sintaxe, geração de patches unificados e refatoração com pegada de memória desprezível.

  • Harness canônico de contexto com poda semântica
  • Suporte a diffs contíguos de alta precisão
  • Integração com git hooks e pipelines locais
// chronokairo-coder --mode=autonomous
$ ckc agent --context=workspace --target=fix-leak
✔ Context index: 1,420 files scanned (18.4ms)
✔ Patch verified: AST zero regression
